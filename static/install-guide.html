📱 AI行情趋势监控 — 安卓手机安装指南

⚡ 你的局域网地址： http://192.168.3.67:18888
确保手机和电脑连接同一个 WiFi，然后在手机浏览器打开此地址。

1 方式一：PWA 安装（推荐，30秒搞定）

PWA 会将网页变成类似原生 App 的体验：桌面图标、全屏、离线缓存。

  1. 手机 Chrome 浏览器打开 http://192.168.3.67:18888
  2. 地址栏右侧会出现 "添加到主屏幕" 提示（或点右上角 ⋮ → 添加到主屏幕）
  3. 点击添加，桌面出现 "AI行情监控" 图标
  4. 点击图标即可全屏使用，像原生 App 一样

※ 支持 Chrome、Edge、Samsung Internet 等 Chromium 内核浏览器。华为/小米自带浏览器也支持。

2 方式二：生成真正的 APK 安装包

如果你想得到一个 .apk 文件（可以发给别人安装），使用微软的在线工具：

  1. 打开 pwabuilder.com
  2. 在输入框填入：http://192.168.3.67:18888
  3. 点击 Start，工具会自动检测 PWA 配置
  4. 在 "Android" 卡片中点击 "Package for Stores"
  5. 下载生成的 .apk 文件
  6. 传到手机，直接安装

※ PWABuilder 使用 Trusted Web Activity (TWA) 技术，生成的 APK 本质上是全屏浏览器壳 + 你的网页，Google Play 合规。

3 方式三：命令行生成 APK（需要配置环境）

如果以后装了 Node.js 和 Java，可以在本机直接生成：

npm install -g @bubblewrap/cli
bubblewrap init --manifest=http://192.168.3.67:18888/static/manifest.json
bubblewrap build

生成的 APK 在项目根目录的 app-release-signed.apk
